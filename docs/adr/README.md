# Architecture Decision Records

ADRs preserve durable conductor decisions that constrain future implementation.
OpenSpec remains authoritative for executable requirements; ADRs explain why a
boundary was chosen. New ADRs use `NNNN-short-title.md` and are append-only
except for status/supersession updates.
